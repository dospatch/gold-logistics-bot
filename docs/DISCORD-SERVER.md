# BC Gold Logistics Discord Server

**Tagline:** Driven by Excellence. United by the Road.  
**Games:** ATS and ETS2

## Roles
- Owner
- Chief Executive Officer
- Operations Manager
- Fleet Manager
- Convoy Manager
- Senior Driver
- Company Driver
- Trainee Driver

## Channel layout
- 📌 INFORMATION: welcome, announcements, company-information, company-rules, driver-roster
- 📝 RECRUITMENT: apply-to-join, application-status, recruitment-support
- 🚛 DRIVER OPERATIONS: driver-chat, ats-drivers, ets2-drivers, delivery-logs, mileage-reports
- 🏁 CONVOY OPERATIONS: convoy-announcements, convoy-schedule, convoy-media
- 🔒 MANAGEMENT: management-chat, applications-review, staff-reports
- 🔊 VOICE: Driver Lounge, ATS Convoy, ETS2 Convoy, Management

## Application workflow
1. Driver uses the application panel or `/apply`.
2. Bot collects game, experience, availability, preferred truck, and motivation.
3. Application is posted as a gold embed in private `#applications-review`.
4. Management reviews and decides in the website portal.
5. Bot updates status and attempts to DM the applicant.

## Permissions
Bot requires View Channels, Send Messages, Embed Links, Read Message History, Use Application Commands, Manage Channels, and Manage Roles for initial setup. Place its role above company roles it must manage. Keep Management private to Owner, CEO, Operations Manager, Fleet Manager, and the bot. Avoid Administrator unless necessary.

## Security
Never commit tokens, OAuth secrets, session keys, `.env` files, or member personal data. Store secrets only in encrypted host environment variables.
